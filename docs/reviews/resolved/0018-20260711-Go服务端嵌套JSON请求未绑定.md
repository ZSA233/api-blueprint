# Go 服务端嵌套 JSON 请求未绑定

- 状态：已修复
- 发现日期：2026-07-11
- 风险分级：高
- 问题性质：生成器正确性缺陷

## 背景与存在性判断

Go server writer 使用请求模型的 truthiness 判断是否生成 `req=json`。`ModelMeta` 的 truthiness 与字段形状有关；当请求体只有一个嵌套模型字段时，模型存在但求值为 `False`，最终生成的路由不会执行 JSON 绑定。

该问题已在真实 HTTP 写接口中复现：客户端发送了合法 JSON，Gin 日志也能看到请求体，但业务实现收到的 `req.Body` 为空。

## 影响与兼容性

- 影响所有 Go server target 中仅由嵌套模型组成的 JSON 请求。
- 接口会稳定失败，可能被上层错误映射为 500。
- 修复只改变此前无法工作的请求绑定，不改变字段或 wire shape。

## 修复记录 / Resolution

- 修复日期：2026-07-11
- 修复方式：以 `model is not None` 判断请求契约是否存在，不再使用 `bool(model)`。
- 回归测试：新增仅含嵌套模型的 JSON 请求，断言生成 `req=json`。
- 验证命令：`uv run pytest tests/codegen/go/server/test_provider.py -q`
